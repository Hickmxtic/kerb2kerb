        Behind the scenes

        Your Build Team

        The four roles that build everything in here, in the order they run. What's listed under each one is real work they've actually done — not a demo.

        01 · ARCHITECT

        Architect

        Turns an idea into a build plan and asks the key questions before anything gets coded — this is Claude, directly, in your conversation.

        • Recently scoped
        • Pricing calculator: job types, free vs. paid postcode lookup, callout + per-mile structure
        • Dashboard: debt vs. emergency fund run in parallel, portfolio manual-only, ideas surfaced from your manifest
        • Growth Toolkit: lead tracker + ad copy combined, plus an honest ads setup guide instead of live campaign management
        02 · CODER

        Coder

        Builds the actual thing from the Architect's plan. A fresh one spins up for each build — no memory between jobs, just the brief.

        • Recently built
        • Pricing calculator, including the offline postcode-district dataset that replaced the live lookup
        • This dashboard — all 7 sections, live bookings, debt/fund/income tracking, portfolio
        • Growth Toolkit — lead tracker, ready-to-copy ad copy, and the ads setup guide
        03 · TESTER

        Tester

        Only job is breaking what the Coder just built. No credit for being nice about it.

        • Recently caught
        • Calculator: a silent £0.00 quote when rates were left at zero, and a negative rate with no warning
        • Dashboard: a booking-panel freeze bug, a debt % mismatch, and unvalidated negative portfolio entries
        • Growth Toolkit: nothing — first clean pass this session, zero bugs found
        04 · MANAGER

        Manager

        Independently re-checks the Coder's and Tester's work, throws out false alarms, and gives the final ship / don't-ship call.

        • Recently ruled on
        • Confirmed all 5 bugs the Tester found on this dashboard by reading the code directly, then set the fix order
        • Growth Toolkit: independently re-verified the Tester's zero-bug report and cleared it to ship as-is
        • Signs off before anything reaches you — nothing here shipped without a Manager pass
